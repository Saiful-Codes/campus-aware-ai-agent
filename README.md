# Campus-Aware Intelligent AI Agent

Capstone project for building an AI-powered mobile application that helps students and staff query campus-related information using natural language.

## Tech Stack
- Mobile: Expo + React Native + TypeScript
- Backend: FastAPI
- Database: PostgreSQL + pgvector
- Telemetry: InfluxDB
- Auth: Firebase Authentication
- AI: OpenAI API + LangChain + PyMuPDF
- Hosting: Render + Supabase

## Repository Structure
- `mobile/` - Expo mobile app
- `backend/` - FastAPI backend
- `docs/` - project documentation
- `data/` - sample local data
- `infra/` - infra and deployment configs
